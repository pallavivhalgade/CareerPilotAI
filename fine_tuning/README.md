# Optional LoRA experiment

This folder is intentionally separate from the core 8 GB local app. A small JSONL dataset can be used to fine-tune an instruction model with PEFT/LoRA on a machine with enough RAM/VRAM.

Core application does NOT require fine-tuning. The portfolio claim should be: “Designed an optional LoRA fine-tuning experiment” unless you actually run training and record metrics.
